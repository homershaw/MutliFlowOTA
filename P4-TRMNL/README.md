# P4-TRMNL release reservation

Reserved for the ESP32-P4 TRMNL controller family.

**No firmware or manifest is published here.** The correct target build and
hardware validation have not yet been identified. Missing release metadata means
unavailable, not permission to fall back to another controller's image.

The existing [XIAO ePaper release](../riot-flow/) identifies
`TRMNL_XIAO_EPAPER`; it is not an approved P4-TRMNL image. Its existing paths
remain unchanged. Do not copy JC-Riot, P4-NANO or XIAO binaries into this folder
as a placeholder.
